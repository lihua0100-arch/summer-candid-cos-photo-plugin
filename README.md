# Summer Candid Cos Photo Plugin

用于生成或编辑单张、写实、自然互动的成年夏日泳装与真人 COS 抓拍照片。

## 安装

在 Codex CLI 中运行：

```bash
codex plugin marketplace add lihua0100-arch/summer-candid-cos-photo-plugin
codex plugin add summer-candid-cos-photo@lihua-summer-photo
```

也可以在 ChatGPT/Codex 桌面应用的 Plugins 页面中添加该 GitHub Marketplace，然后安装 **夏日泳装自然抓拍**。

安装后请新建聊天，输入 `@` 并选择 **夏日泳装自然抓拍**，再描述要生成或编辑的图片。

## 示例

```text
@夏日泳装自然抓拍 生成一张四位成年女性朋友在海边玩水的自然抓拍照片。
```

插件仅包含生成规则、视觉参数和通用图标，不包含用户照片、聊天记录、账号信息、密钥或其他个人数据。
